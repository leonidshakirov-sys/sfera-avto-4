# СфераАвто

Лендинг охраняемой парковки торгово-сервисного комплекса СфераАвто на первой линии Варшавского шоссе и МКАД.

## Что на сайте

- Открытая охраняемая стоянка на территории комплекса, не крытый и не круглосуточный паркинг
- Адрес: Москва, Чертаново Южное, МКАД 32-й км, владение 15
- Ближайшее метро — Аннино
- Логотип по вывеске на здании: «СФЕРА АВТО», красная плашка «Автосервис / Япония + Корея»

## Локальный просмотр

```bash
npm run serve
```

Сайт: `http://127.0.0.1:4173`

## Публикация

Готовый сайт в папке `site`. GitHub Pages публикует её через `.github/workflows/pages.yml`.
