# Сфера-Авто

Лендинг охраняемой крытой парковки ПАСК «Сфера-Авто» в Москве, район Братеево.

## Что на сайте

- Главная страница с заявкой на машиноместо
- Блоки о стоянке, оформлении места, тарифах по запросу и маршруте от метро Борисово
- Политика конфиденциальности и страница благодарности после формы
- Schema.org `ParkingFacility`, Open Graph, `sitemap.xml` и `robots.txt`

## Локальный просмотр

```bash
npm run serve
```

Сайт откроется по адресу `http://127.0.0.1:4173`.

## Публикация

Готовый сайт лежит в папке `site`.

- **GitHub Pages:** после слияния в `main` workflow `.github/workflows/pages.yml` публикует содержимое `site`. В настройках репозитория нужно выбрать Source: GitHub Actions.
- **Netlify:** publish directory — `site`, конфиг уже в `netlify.toml`.
- **Vercel:** output directory — `site`, конфиг уже в `vercel.json`.

Публичный адрес GitHub Pages: `https://leonidshakirov-sys.github.io/sfera-avto-4/`
